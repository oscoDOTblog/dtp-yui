# CV2 v1: OpenClaw Browser Gmail Summary

## Summary

Replace the current job-application workflow with one simple first milestone:

- Start OpenClaw’s browser plugin using the `user` profile.
- Launch/attach to the signed-in Chrome session.
- Open Gmail.
- Read the latest 50 email subject headers.
- Print the 50 subjects and a concise Ollama summary in the terminal.
- Save the raw subjects and summary as local JSON.

OpenClaw’s `user` profile is the correct choice because it uses the user’s signed-in Chrome session; the isolated `openclaw` profile is not needed for this version. [OpenClaw browser documentation](https://docs.openclaw.ai/tools/browser)

## Implementation Changes

- Remove the current job-discovery, application, document-generation, and approval workflow from the active v1 runner.
- Remove Playwright usage entirely.
- Invoke the installed OpenClaw CLI/browser plugin directly.
- Start or verify the OpenClaw `user` browser profile.
- Navigate to Gmail using OpenClaw browser actions.
- Read only the latest 50 subject headers; do not open message bodies or links.
- Use Ollama `qwen3:8b` to summarize the subject list.
- Print intermediate terminal output for each stage:
  - OpenClaw startup
  - browser profile status
  - Gmail navigation
  - Gmail login check
  - subject collection progress, e.g. `12/50`
  - summary generation
  - JSON save location
- If Gmail is not already signed in, stop with an actionable terminal error. Do not implement login automation.

## JSON Output

Create one run directory:

```text
cv2/runs/<run-id>/
```

Write:

- `run.json` — status, timestamps, profile, counts, errors
- `emails.json` — the 50 subject records
- `summary.json` — Ollama summary and key themes
- `events.jsonl` — timestamped intermediate progress events

Example subject record:

```json
{
  "position": 1,
  "subject": "Your application was viewed",
  "sender": "Example Company",
  "date": "2026-10-14",
  "source": "gmail"
}
```

## Test Plan

- Verify the runner uses OpenClaw’s `user` profile.
- Verify Chrome opens or attaches visibly.
- Verify a signed-in Gmail session is detected.
- Verify exactly up to 50 newest subject headers are collected.
- Verify no email bodies or links are opened.
- Verify progress appears while collection is running.
- Verify Ollama generates a summary from only the collected subjects.
- Verify all JSON files are written even when Gmail is empty or an error occurs.
- Verify a clear failure is recorded when the `user` profile or browser plugin is unavailable.

## Assumptions

- Gmail is already signed in within OpenClaw’s `user` browser profile.
- “Latest 50” means Gmail’s current newest-first inbox/search result ordering.
- The first version summarizes subject metadata only.
- No job scoring, CV generation, applications, Telegram, Next.js, or background processing is included.
- OpenClaw remains responsible for all browser interaction; CV2 only orchestrates the run, displays progress, invokes Ollama, and persists JSON.
