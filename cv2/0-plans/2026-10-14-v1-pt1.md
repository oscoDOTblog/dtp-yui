# CV2 Minimal Local Terminal Agent

## Summary

Build a single local OpenClaw + Ollama process that:

1. Opens a visible Chrome browser.
2. Searches Gmail for job links.
3. Reviews jobs against the existing CV.
4. Generates tailored CVs and cover letters.
5. Fills application forms.
6. Pauses for terminal approval before submission.
7. Prints all progress in the terminal.
8. Saves every result locally as JSON.

No Next.js, Telegram, remote access, CDP, Docker, or background services.

## Local Workflow

- Launch visible Chrome with a persistent local profile.
- Open Gmail and search the whole inbox for job-related messages.
- Extract and deduplicate listing links.
- Process one job at a time.
- Use Ollama `qwen3:8b` for compatibility scoring and document generation.
- Reuse CV1’s existing candidate profile, evidence, scoring, and application logic.
- Save generated CV and cover-letter files under `cv2/generated-applications`.
- Require terminal approval before every final submission.

## Terminal Approval

Before submission:

```text
Ready to submit:
Company: Example Corp
Role: Software Engineer
Compatibility: 82%

Type APPROVE to submit, SKIP to skip, or PAUSE to stop:
```

Only `APPROVE` submits the application.

CAPTCHA, sensitive questions, and uncertain fields pause the agent and request terminal input.

## JSON Output

Save results under:

```text
cv2/runs/<run-id>/
```

Files:

- `run.json` — overall run metadata and summary
- `emails.json` — Gmail messages inspected and extracted links
- `jobs.json` — job details, source URL, score, recommendation, and status
- `applications.json` — application progress, filled fields, approval, and submission result
- `events.jsonl` — chronological machine-readable event log
- `documents.json` — generated document paths and generation metadata

Each job record should include:

```json
{
  "jobId": "stable-local-id",
  "company": "Example Corp",
  "title": "Software Engineer",
  "listingUrl": "https://example.com/job",
  "sourceEmailId": "gmail-message-id",
  "compatibilityScore": 82,
  "recommendation": "apply",
  "status": "awaiting_approval",
  "resumePath": "generated-applications/example-corp-software-engineer/resume.pdf",
  "coverLetterPath": "generated-applications/example-corp-software-engineer/cover-letter.pdf",
  "submittedAt": null,
  "error": null
}
```

Write JSON after every meaningful state change so interrupted runs retain their progress.

## Configuration

- Visible Chrome browser
- Persistent local browser profile
- Gmail accessed through the browser
- Ollama model: `qwen3:8b`
- One job at a time
- Required approval before submission
- Terminal-only interaction
- Local JSON persistence
- No CDP
- No remote access
- No Next.js
- No Telegram
- No Docker requirement for the first version
